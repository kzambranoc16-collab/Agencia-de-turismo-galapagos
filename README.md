# Ruta Chatham — Portal web de agencia de turismo

**Nombre del estudiante:** Kandy Maricela Zambrano Cobeña

**Destino turístico asignado:** Isla San Cristóbal — Galápagos

## Descripción del proyecto

Sitio web de cinco páginas para una agencia de turismo ficticia ("Ruta Chatham")
enfocada en Isla San Cristóbal, Galápagos. Presenta a la agencia, seis atractivos
turísticos investigados, seis servicios/paquetes turísticos, información
institucional y un formulario de contacto/reserva.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 (Flexbox, CSS Grid, Box Model, pseudo-clases `:hover` y `:focus`, `@media`)
- Sin frameworks ni librerías externas
- GitHub y GitHub Pages para el control de versiones y la publicación
